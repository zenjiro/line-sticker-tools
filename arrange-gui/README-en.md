# sticker-gui

A Web application to organize image files for LINE sticker applications and export them as ZIP files.

**🔗 [Open sticker-gui](https://zenjiro.github.io/line-sticker-tools/)**

## Key Features

- **Import Images**: Load images via drag & drop or file selection.
- **Intuitive Organization**: Smoothly sort and select images using keyboard shortcuts.
- **Main/Tab Image Settings**: Easily specify main and tab images for your sticker set.
- **Trash Function**: Temporarily move unwanted images to trash and restore them if needed.
- **ZIP Export**: Checks if the number of images meets LINE Creators Market regulations (8, 16, 24, 32, 40 images) and creates a ZIP file in the required format.

## Keyboard Shortcuts

The following shortcuts are available for efficient work.

| Key | Action |
|---|---|
| `Arrow Keys` | Move focus |
| `Alt` + `Arrow Keys` | Move selected image(s) |
| `Shift` + `Arrow Keys` | Range selection |
| `Space` | Toggle selection (multi-select) |
| `M` | Set selected image as **Main Image** |
| `T` | Set selected image as **Tab Image** |
| `Delete` / `Backspace` | Move to Trash / Restore |
| `Ctrl` + `X` | Cut image(s) |
| `Ctrl` + `V` | Paste (Insert) image(s) |
| `Esc` | Cancel Cut / Deselect |
| `Ctrl` + `+` / `-` | Zoom In / Out |
| `Ctrl` + `0` | Reset Zoom |
| `E` | Export ZIP |
