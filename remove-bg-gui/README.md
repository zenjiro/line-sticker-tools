# 背景削除ツール (GUI)

画像の背景を削除するためのWebツールです。
自動検出による背景削除に加え、手動での閾値調整が可能です。

## 機能

- **背景削除**: Canvas APIを使用してブラウザ内で高速に処理
- **閾値調整**: 自動設定値をベースに、キーボード操作で微調整
- **一括処理**: 複数の画像をまとめて処理・ダウンロード
- **サイズ調整**: ウインドウサイズに合わせて画像の表示サイズを自動調整
- **ダークモード**: システム設定または手動切り替え

## 使い方

1. 画像を画面にドラッグ&ドロップ（複数可）
2. 処理結果を確認
   - **矢印キー**:画像の選択（フォーカス）
   - **J / N**: 透明範囲を広げる（閾値を上げる）
   - **K / P**: 透明範囲を狭める（閾値を下げる）
3. **E**: 画像を保存
   - 1枚の場合：PNG画像として保存
   - 複数枚の場合：ZIPファイルとしてまとめて保存

## 開発

### 依存関係のインストール

```bash
npm install
```

### 開発サーバーの起動

```bash
npm run dev
```
